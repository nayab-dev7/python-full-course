# Python Full Course

A collection of Python programs, exercises, assignments and small projects that I write while learning Python as part of my AI studies at Aror University, Sukkur.

This repository is updated regularly as I learn new topics.

## What's Inside

The code is organized topic by topic, from basics to more advanced concepts:

- Variables, data types and operators
- Input and output
- Conditions (`if`, `elif`, `else`)
- Loops (`for`, `while`)
- Lists, tuples, sets and dictionaries
- Functions
- File handling
- Object-Oriented Programming (OOP)
- Small practice projects

> Folders and files will be added as I progress through the course.

## How to Run

1. Install Python 3 from [python.org](https://www.python.org/downloads/)
2. Clone this repository:
   ```bash
   git clone https://github.com/nayab-dev7/python-full-course.git
   ```
3. Go into the folder:
   ```bash
   cd python-full-course
   ```
4. Run any file:
   ```bash
   python filename.py
   ```
